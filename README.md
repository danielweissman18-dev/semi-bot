# 🤖 סמי בוט – מדריך הגדרה מלא

## מה הבוט יודע לעשות?

- **📅 הודעת בוקר** – כל יום ב-9:30 שולח לשניכם סטטוס לקוחות
- **➕ הוספת לקוח** – שלח `תפריט` → 1
- **✏️ עדכון סטטוס** – שלח `תפריט` → 2, או ישירות `שם עסק העביר מקדמה`
- **📄 הצעת מחיר PDF** – שלח `תפריט` → 3
- **🎉 אישור הצעה** – שלח `שם עסק אישר את ההצעה` → מוסיף ללקוחות אוטומטית

---

## שלב 1 – הוסף את הלוגו שלך

העתק את קובץ הלוגו שלך לתוך תיקיית הפרויקט ושנה שם ל:

> אם אתה מריץ את הפרויקט מקומית ב-Windows, הקוד תומך בזיהוי אוטומטי של Chrome / Edge כדי להפעיל את whatsapp-web.js.

```
logo.png
```

> אם אין לוגו – הבוט יציג IWDZN בטקסט. אפשר להוסיף בהמשך.

## שלב 2 – Deploy ב-Railway (חינם)

### 2.1 – פתח חשבון Railway
1. היכנס ל-[railway.app](https://railway.app)
2. לחץ **Sign Up** → התחבר עם **GitHub**
3. צור חשבון GitHub בחינם אם אין לך

### 2.2 – העלה את הקוד ל-GitHub
1. צור repository חדש ב-GitHub בשם `sami-bot`
2. העלה את כל קבצי הפרויקט:
   ```
   index.js
   config.js
   scheduler.js
   pdfGenerator.js
   package.json
   clients.json
   logo.png  ← שלך
   ```
3. **.gitignore** – צור קובץ זה עם התוכן:
   ```
   node_modules/
   .wwebjs_auth/
   .wwebjs_cache/
   quotes/
   ```

> טיפ: אל תוסיף את `clients.json` ל-.gitignore אם אתה רוצה לשמור קובץ דוגמה או נתוני התחלה בגיט.

### 2.3 – Deploy ב-Railway
1. ב-Railway לחץ **New Project** → **Deploy from GitHub repo**
2. בחר את `sami-bot`
3. Railway יזהה אוטומטית שזה Node.js ויריץ `npm start`

### 2.4 – סרוק QR Code
1. לאחר ה-Deploy, לחץ על השירות → לשונית **Logs**
2. תראה QR Code בלוגים
3. פתח ווצאפ בטלפון הבוט → **Linked Devices** → **Link a Device**
4. סרוק את ה-QR – הבוט מחובר! 🎉

> **טיפ:** לאחר חיבור ראשון, ה-Session נשמר אוטומטית. Railway יישמור אותו גם בין Restarts.

---

## שלב 3 – הוסף Persistent Storage לקבצים

כדי ש-`clients.json` לא יימחק בכל Deploy:

1. ב-Railway לחץ על הפרויקט → **Volumes**
2. **Add Volume** → Mount Path: `/app`
3. זהו – הנתונים נשמרים לצמיתות
